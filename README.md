## About Me

Passionate developer who loves building practical solutions and experimenting with new technologies. From Minecraft server plugins to full-stack web applications and Discord bots, I enjoy creating tools that make life easier.

- **Minecraft Plugin Developer** - Crafting server-side modifications with Java (Paper/Spigot)
- **Web Developer** - Building modern web applications with Next.js
- **Bot Developer** - Discord bots with Python & dashboard frontends
- **Self-Hoster** - Running everything on my own infrastructure
