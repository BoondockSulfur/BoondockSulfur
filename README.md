## About Me

Developer who loves building practical tools and experimenting with new technologies — from Minecraft server plugins and native Linux apps to full-stack web applications and Discord bots.

- **Minecraft Plugin Developer** – server-side plugins in Java for Paper, Folia & Spigot (1.21 – 26.x)
- **Desktop Developer** – native Linux apps with Rust & Tauri
- **Web Developer** – modern web apps with Next.js, React & Prisma
- **Bot Developer** – Discord bots with Python & web dashboards
- **Self-Hoster & Linux Tinkerer** – running everything on my own infrastructure
